# poi-walk

A small map template designed for self-guided tours of Points of Interest (POIs). 

The initial concept was for local "tree walks", where a park visitor can tour a selection of notable trees on a predefined path.

The code is mostly Maplibre GL JS. I did need to fork [maplibre-gl-compass](https://github.com/kfinity/maplibre-gl-compass) to get it to play nicely with Maplibre's geolocate control.
